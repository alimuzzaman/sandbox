How to use it

Three commands to set up, then one phrase in any Claude session.

  1. Run the one-line installer — it downloads and unpacks the sandbox to ~/sandbox, checks prerequisites (offering to install what's missing), boots Docker, installs WordPress, and wires Claude to the MCP server.
  2. You're live at http://localhost:8188. sb becomes a global command, so sb web, sb instances, etc. work from anywhere.
  3. In any Claude session, say focus <plugin> — e.g. focus embedpress. That's it.

Prerequisites: Docker (running) · Python 3.9+ · Claude Code (or any MCP client — Cursor, Cline, Continue, Zed).

Prefer git? git clone https://github.com/wpdevelopers/sandbox → cd sandbox → ./sb setup — does the same thing.

Early stage. Sandbox is still very new — if you run into any errors, please report them on GitHub. Can't access the repo? Just ping me. Contributions welcome.
