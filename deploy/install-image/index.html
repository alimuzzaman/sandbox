A live, disposable WordPress environment wired to Claude (or any MCP client). Claude runs WP-CLI, hits the REST API and database, opens pages in a real browser, reads and edits your plugin's code, and fixes bugs end-to-end — instead of guessing.

macOS / Linux. Installs prerequisites, sets up WordPress, wires Claude — step by step.

Build

Claude implements features against a running install and verifies them live — not from memory.

Reproduce

Hand Claude the environment and it reproduces the bug on a real stack — confirmed, not assumed.

Fix & prove

Reproduce → fix the real code → re-verify in the same environment. Fast, and proven.

What the one command does

  1. Checks prerequisites and offers to install what's missing (Python, Docker) — your call, never silent.
  2. Downloads and unpacks the sandbox to ~/sandbox — no git, no repo access needed.
  3. Boots Docker, installs WordPress, builds the MCP server, and wires Claude to it.
  4. You're live at http://localhost:8188 — then just tell Claude focus <plugin>.
